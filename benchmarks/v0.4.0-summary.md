## Notes

- `bench-sydraql` is intentionally focused on the currently supported compiled subset plus an explicit unsupported query to verify fallback visibility.
- `bench-cas` is measuring bundle and maintenance paths, not broad ingest throughput.
- `bench-alloc` should be run serially when sweeping multiple cardinalities because it uses timestamped temp directories under `.zig-cache/tmp`.
